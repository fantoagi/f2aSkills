# 去AI味门禁（de-AI humanize gates）

> 中文改写稿的「去AI味」处理规则。本文的 H2-H5 是风格子门禁命名空间，不是 v2 的 G1-G5 质量闸门；与 `scripts/c2_scan.py` 扫描 16（检测）配套：扫描 16 报命中，本文给改写判断——怎么改、用多大力、能删多少、哪些场景不动。

## 一、适用边界

### 不适用（非虚构，以下不处理）
- **心理外化**：把主观状态外化成动作（「他很紧张→手在抖」）——非虚构不需要
- **对话腔**：口误 / 粗话 / 即兴——无对话场景
- **伏笔 / 钩子 / 主角 / 人设 / 剧情**：属内容层，非虚构无情节

### 口语化门禁 —— 关闭
去AI味**只打「AI 腔 / 套路 / 解释腔 / 升华」，绝不向白话方向改**。mode-B（快讯/正式克制）register 禁口语化。既有扫描 10/12（标题 / 正文口语）是 register 控制线，与本门禁无冲突，不重复处理。

## 二、打击对象（改「怎么说」，不改「说什么」）

### H2 句式去套路（所有模式都查）
| 套路 | 表现 | 去法 |
|---|---|---|
| 否定翻转 | `不是A而是B` | 刻意对比可保留；套现式改直述 |
| 与其说…不如说 | `与其说A不如说B` | 拆回两层直接陈述 |
| 万能状语 | `，带着X` | 最毒，去副词直述 |
| 洞察路标 | `更微妙的是 / 耐人寻味的是 / 值得注意的是` | 删，或用具体事实落地 |
| 总结路标冒号 | `一句话总结： / 总的来说 / 归根结底` | 用结论句替换，别自报预告 |

### H3 解释腔 / 上帝感 / 深度解析腔（最大缺口）
| 表现 | 去法 |
|---|---|
| 解释因果：`之所以…是因为 / 这意味着 / 原因在于` | 交给事实自己说话，删除强解释 |
| 剧透/定性：`殊不知 / 其实质是 / 本质上 / 说到底` | 删或将判断后置 |
| 软评判：`堪称 / 恰到好处 / 绝佳` | 用可验证细节替代万能赞美 |
| 无来源假细节：`凌晨三点 / 深夜两点` | 无来源则删，不补时间 |

### H4 节奏均匀（打破机械排比）
| 体征 | 阈值 | 去法 |
|---|---|---|
| 三连以上短句排比 | ≥1 处/篇 | 打散成参差句长，长短句交替 |
| 破折号 `——` | ≤2/篇 | 删，别用破折号制造顿挫 |
| 感叹号 `！` | ≤1/千字 | 删或改陈述，调性克制 |
| 单句 ≥3 从句（长定语链） | ≥2 句/篇 | 拆句 |

### H5 结尾去升华
| 表现 | 去法 |
|---|---|
| `未来已来 / 这次事件告诉我们 / 它启示我们 / 我们有理由相信` | 换**具体判断 + 数字 + 结论**，不喊口号 |
| `在当今这个…时代` | 删泛化时代定语，直接给事实 |

## 三、模式感知强度（不同 mode 用不同力度）

| 模式 | register | 去AI味强度 | 说明 |
|---|---|---|---|
| **A** 大白话专栏 | 口语，亲近 | **强（重）** | AI 腔最违和，全力去 |
| **B** 快讯/正式克制 | 书面、克制 | **弱（轻/中）** | 只去 AI 套路与升华；**不做口语化** |
| **C** 转述 | 转述 | **中** | 去解释腔、去路标 |
| **D** 认知重构 | 论说文 | **中/重** | 去升华，留犀利判断 |
| **R** 微调 | 忠实原稿 | **轻** | 只去明显 AI 腔，不主动改写 |

**强度只影响「改不改 / 改多少」，不影响「哪几类查」**——H2/H3/H4/H5 所有模式都查，只是 B/R 查完往往判定不强改。

## 四、量化定级（6 指标，取最高档）

命中后按密度定级，作为「要不要认真去味」的开关：

| # | 指标 | 轻 | 中 | 重 |
|---|---|---|---|---|
| 1 | AI 腔句式密度 | <1/千字 | 1–2.5/千字 | >2.5/千字 |
| 2 | 连排比段数 | 0 | 1–2 | ≥3 |
| 3 | 破折号/篇 | ≤2 | 3–4 | >4 |
| 4 | 解释腔密度 | <0.5/千字 | 0.5–1.5/千字 | >1.5/千字 |
| 5 | 结尾升华股 | 0 | 1 | ≥2 |
| 6 | 长定语链句数 | <2 | 2–4 | >4 |

**取最高档定级**（不是平均）。扫描 16 用命中密度与破折号做机械默认值；agent 按上表人工复核。

## 五、删除比例保护（防「去了人味」）

| 定级 | 最多删原文占比 |
|---|---|
| 轻 | ≤15% |
| 中 | ≤25% |
| 重 | ≤35% |

- **不整段删**：优先改词、改句式，不整段砍。
- **不删功能**：不删事实、不删数字、不删反常识点——那正是文章价值。
- **冲突时降级**：改到上限还「带着 AI 腔」？标 `[需复核]` 转人工，而不是硬删到丢事实。
- **只改怎么说**：不新增原文没有的观点 / 结论 / 数字。

## 六、收敛终止

- 同一段**连续 2 轮无新改动** → 该段停。
- 全文**3 轮上限**；第 3 轮仍有 ≥10 处 → 标 `[需复核]` 转人工。
- 去味是润色不是重写：**收敛比去尽更重要**，越到后面每轮收益越递减。
