# 跨文化术语查表 (Cross-cultural Terms)

> **使用时机**：模式 C 公众号改编子模式 最小交付清单 第 6 条 — 每遇到下表中的英文/中文词，**必查**本表再译。
> **反陷阱**：**禁止**用 LLM 直觉对英文 jargon 1:1 翻译。**禁止**不加查表就把"Pitch Deck"译成"推销甲板"或"投售甲板"。

## 11. 通用规则

1. **缩写直接保留**：所有 3 字母以上行业缩写（KPI / OKR / MVP / RAG / SOC / SWE-bench / GAIA / SLA / SLO 等）**不翻译**，保留英文
2. **直译陷阱列表**（以下英文术语在中文里**禁止**按字面意思翻译）：
   - `wrapper` → 套壳（不是"包装器"）
   - `framework` → 框架（不是"骨架"）
   - `pipeline` → 管线 / 流水线（看语境，不译"管道"）
   - `stack` → 技术栈（不是"堆栈"，除非是计算机内存场景）
   - `feed` → 推送 / 喂入（看语境，不译"饲料"）
   - `kill` → 杀掉（看语境）/ 终止（看语境），不译"谋杀"
   - `trigger` → 触发 / 触发器（看语境），不译"扳机"
   - `anchor` → 锚点（不是"锚定器"）
   - `outreach` → 主动营销 / 联系（不是"外展"）
   - `onboarding` → 引导 / 入门（不是"登船"）
   - `cliffhanger` → 悬念（不是"悬崖"）
3. **行业子圈子优先**：术语在译前先想清楚"中文读者在哪个圈子会读到"——AI 圈 / 投资圈 / 创业圈 / 营销圈 / 设计圈 / 安全圈——每个圈子有自己的术语库
4. **直译 + 上下文双校验**：光看英文术语 1:1 译不可靠，必须看这个术语在原句里的**语境**——harness 在 AI Agent 语境是"调度框架"，在硬件语境是"马具"
5. **首次出现加注（按读者分层）**：核心术语首次出现时用 `中文（English）` 格式加注，如 "**harness（调度框架）**"；后续章节仅用中文。**目标读者为行业资深者（高级开发/创投/研究圈）时，仅对"确有必要"的概念加注**——专有造词（如 American Dynamism）、新词/缩写（如 RSI、Neo-labs）值得保留英文；通用术语（TAM、secondary、margin call、revenue stream）不加注——中文精准时英文括号打断阅读心流，显得不自信（2026-08-10 用户反馈：四类通用术语英文备注全部删除，仅保留 Neo-labs 与 RSI 两处）
6. **概念词/财务指标注释分级（2026-08-10 补充）**：两类词不适用规则 5 的最小化策略，**必须加注**：
   - **概念性行话**：首次出现必加英文注释——杠铃分布 (Barbell Distribution)、AI 忍者 (AI Ninjas)、人机协同 (Human-AI Hybrid)、核心业务系统 (Systems of Record)、直接处理总账 (General Ledger)（2026-08-10 AI Adoption 文章用户明确要求补注）
   - **财务/行业指标**：首次出现必加中文释义——EBIT（息税前利润）（2026-08-10 用户要求"面向泛商业受众补充专业解释"）
   - 通用术语（TAM、EBITDA 外的常见词）仍按规则 5 最小化

## 12. 何时跳过查表

- 术语已在 `references/glossary-ai.md` 中收录的（glossary 优先）
- 翻译场景明确为**学术论文 / 论文翻译**——保留英文术语是学术规范
- 读者场景明确为**纯技术社群**——可直接用英文术语（如 PyTorch 文档、arXiv 论文）
