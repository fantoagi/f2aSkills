# 资深编辑 Polish 清单 (Editor Polish Checklist)

> **使用时机**：模式 C 公众号改编子模式 最小交付清单 第 7 条 — 在 C2 grep 通过后、最终交付前必跑本清单。
> **反陷阱**：C2 grep 抓的是"硬错"（翻译腔/动宾跨域/名词堆叠）。**资深编辑 catch 的是"软错"**——jargon 直译、营销圈通用语、微节奏。两者互补。
> **2026-06-09 案例**：30 prompts 翻译走完 C2 grep 0 触发，但资深编辑视角下发现 16 处软错（如 "20 万+ 粉丝的初学者" 歧义、"自含" 直译 jargon、"反馈给到者" 缝合职场黑话、"投资人 deck" 跨文化未对齐等）。**C2 全过 ≠ 公众号可发**。

## 优先级分层（反检查清单疲劳）

12 节全量执行在 token 和注意力上不可持续。按 P0/P1/P2 三层执行：

| 层级 | 含义 | 执行规则 |
|------|------|---------|
| **P0** | 必查，每篇逐项过 | 漏一项 = 交付不完整 |
| **P1** | 抽样查，每篇抽 3-5 项 | 按源材料特征选最可能触发的项 |
| **P2** | 按需查，有明确触发信号时 | 无触发信号可跳过 |

**P1 抽样规则**：不随机——根据源材料特征选择最可能触发的 P1 节。X/Twitter 源材料优先查 §3（营销圈）+ §9（hook 密度）；学术/技术论文源材料优先查 §4（微节奏）+ §5（长难句）；播客/访谈源材料优先查 §2（跨文化）+ §9（hook 密度）。

## 1. 英文 jargon 直译陷阱（最高优先级） 🔴 P0

英文 jargon 在中文里**完全没有**直译版本时，**必查** `cross-cultural-terms.md` 找正确译法。**禁止** LLM 直觉对译。

| ❌ 错误译法（直译） | ✅ 正确译法 | 类别 |
|--------------------|-----------|------|
| 自含（self-contained） | 自成一体 / 信息闭环 | AI |
| 反馈给到者（Feedback Giver） | 反馈提供者 | AI |
| 套壳 | 套壳（OK，但不要"包装器"） | AI |
| 马具 / 挽具 | 调度框架 | AI（语境：harness 在 AI Agent 是系统层） |
| 投售甲板 | 投资人路演 PPT / BP | VC |
| 牵引力 | 业务进展 / 增长数据 | VC |
| 跑道 | 资金可支撑月数 | VC |
| 烧钱率 / 燃烧率 | 烧钱速度 | VC |
| 钩子 | 钩子（OK，但不要"鱼钩"） | 内容 |
| 鱼钩 / 诱饵 | 钩子 / 钩子内容 | 内容 |
| 登船 | 引导 / 入门 | 产品 |
| 武器化 | 武器化（中文可用）或 强化（看语境） | 安全 |
| 杀伤链（kill chain） | 杀伤链 / 攻击链（两个都接受） | 安全 |
| 嫌疑人（suspect） | 嫌疑行为 / 异常行为 | 安全（避免妖魔化） |
| 漏洞 | 漏洞（OK） | 安全 |
| 零日漏洞 | 0day / 零日漏洞 | 安全 |
| 抠脚（k-means 的 k） | 簇数 / 聚类数 | ML |
| 神经元（perceptron 译） | 感知机（perceptron）/ 神经元（neuron） | ML |
| 反向传播 | 反向传播（OK） | ML |
| 推理引擎 | 推理引擎（OK） | AI |
| 经纪人 / 经纪公司 | 代理 / 经纪 / broker（看语境） | 金融 |

## 2. 跨文化行业词汇（中美不同圈子讲法不同） 🟡 P1

`cross-cultural-terms.md` 已经有完整表。本节是 top 5 最易踩的:

| 英文术语 | 美国 AI/VC 圈 | 国内圈 | 注意 |
|----------|------------|-------|------|
| `Pitch Deck` | Pitch Deck | 投资人路演 PPT / BP | **本次踩过** |
| `Traction` | Traction | 业务进展 / 增长数据 | **本次踩过** |

## 3. 营销圈通用语（替代翻译腔） 🟡 P1

公众号 / 商业媒体有自己的一套营销黑话。**禁止**用英文 jargon 直译；用营销圈中文通用词。

| ❌ 翻译腔 | ✅ 营销圈通用语 | 上下文 |
|----------|--------------|------|
| 意外断言 | **反直觉断言** | 标题公式 |
| 表达完整 / 表达完毕 | **表达完整** | 句式 |
| 无情剔除 / 斩断 / 杀掉 | **无情剔除**（杀手级编辑场景）| 锋利感 |
| 跑出完全不一样 | **运转起完全不一样** | 节奏 |
| 拆解从句 | **拆成短句** / **拆成几个分句** | 动作 |
| 自含 | **自成一体** / **信息闭环** | 自含的英文反义 |
| 主要内容 | **核心内容** / **干货** | 内容创作 |
| 输入输出 | **输入 → 输出** | 产品 / 工程 |
| 大部分 | **绝大多数** / **八成** | 数据 |
| 许多 | **许多**（看语境，营销语境可用）/ **大量** | 数量 |
| 一些 | **一些**（看语境，营销语境可用） | 数量 |
| 重要 | **关键**（更专业）/ **重要**（更通俗）| 修饰 |
| 巨大 | **巨大**（口语）/ **显著**（专业） | 程度 |
| 大量 | **大量**（口语）/ **海量**（公众号爆款词）| 数量 |
| 行业领先 | **行业领先**（看语境）| 修饰 |
| 颠覆性 | **颠覆性**（已通用）| 修饰 |
| 赋能 | **赋能**（已通用，但慎用避免 AI 味）| 商业 |
| 闭环 | **闭环**（已通用，但慎用）| 商业 |
| 抓手 | **抓手**（慎用避免官腔）| 商业 |
| 势能 | **势能**（慎用避免 AI 味）| 商业 |
| 心智 | **心智**（慎用避免公众号爆款词堆叠）| 营销 |
| 底层逻辑 | **底层逻辑**（慎用避免公众号黑话）| 营销 |
| 颗粒度 | **颗粒度**（慎用避免 AI 味）| 商业 |
| 复盘 | **复盘**（OK） | 商业 |
| 拉齐 | **拉齐**（OK） | 商业 |
| 赋能 / 抓手 / 势能 | 用具体动作替代 | 商业 |

## 4. 微节奏 / 微气势（中文的气口） 🟡 P1

中文有"气"，需要动词 + 对象的搭配。**禁止**英文直译的"动词 + 名词"组合。

| ❌ 直译搭配 | ✅ 自然搭配 | 类别 |
|------------|------------|------|
| 恢复差距 | **弥合差距** | 动宾 |
| 拉数字 | **增至 / 跃升至** | 动宾 |
| 推价格 | **推高 / 抬升** | 动宾 |
| 卸载任务 | **交由 X 处理** | 动宾 |
| 削减成本 | **压缩成本 / 砍成本** | 动宾 |
| 跑出 | **运转起**（更适合正式语境）| 动宾 |
| 杀掉 | **无情剔除 / 斩断** | 动宾 |
| 表达完整 | **表达完整** | 动宾（OK） |
| 摘录 | **摘录 / 摘出** | 动宾 |
| 找出问题 | **发现 / 锁定** | 动宾 |
| 解决（用于人） | **解法 / 答案**（人不能被"解决"） | 动宾 |
| 涉及 / 牵扯 | **涉及**（"牵扯"过于口语） | 动宾 |
| 摆出 / 摆好 | **摆出 / 准备就绪** | 动宾 |
| 锁定 | **锁定 / 圈定** | 动宾 |
| 抓住 | **抓住 / 紧扣** | 动宾 |
| 兜售（pitch） | **推介 / 简报**（兜售偏销售） | 动宾 |

## 5. 长难句拆短 🟡 P1

中文重短句。一段超 30 字就要拆。**禁止**机械照搬英文长句。

| ❌ 长句 | ✅ 拆短 |
|--------|----------|
| 3 个工具的列表以顿号连接，工具名都是英文 | 工具名中文译 + 工具说明分多句 |
| 定语从句后置 `X 是 Y 提供的 Z` | 拆成"X 是 Y 提供的，它用于 Z" |
| 多层嵌套的 `A that does B by doing C through D` | 拆成" A 通过 D 完成 C，从而实现 B" |
| 同位语堆叠 `北京的，中国的，2026 年的，5 月的 X` | 拆成"X 来自北京，于 2026 年 5 月发布" |

## 6. 英文 jargon 首次出现的加注 🔴 P0

每篇文章首次出现的核心 jargon 必加注（`中文（English）` 格式），后续章节仅用中文。

| ✅ 必加注 | 加注位置 |
|---------|----------|
| `harness` | 首次出现 "harness" 时 |
| `JD` | 首次出现 "JD" 时 |
| `SOC` | 首次出现 "SOC" 时 |
| `Pitch Deck` | 首次出现 "Pitch Deck" 时 |
| `TAM/SAM/SOM` | 首次出现 "TAM/SAM/SOM" 时 |

## 7. 微气势：动词选择 🟢 P2

中文有"狠/快/准/稳"四种动词气质。**禁止**用同一种动词串场。

| 想要气质 | 推荐动词 | 避免用 |
|----------|----------|-------|
| 狠 / 锋利 | 砍、斩、断、剔除、撕、砸 | 删除（温）|
| 快 / 立刻 | 即刻、即时、马上、立刻 | 之后（拖延）|
| 准 / 精确 | 锁定、锚定、瞄准、命中 | 决定（模糊）|
| 稳 / 持续 | 沉淀、积累、固化 | 持续（平庸）|
| 狠/猛进 | 突进、飞跃、跨越式 | 慢慢推进（拖）|

## 8. 段首/段尾的回响 🟢 P2

每章首尾应有"回响"——首句抛问题/数据，末句给结论或 CTA。**禁止**首尾话题断裂。

| ❌ 断裂 | ✅ 回响 |
|--------|--------|
| 开头说"AI 工程师的薪资涨 30%"，结尾"按部就班地学" | 开头数据 → 结尾"想拿这个涨幅，先做 X 件事" |
| 开头"今天聊 agentic"，结尾"祝你成功" | 开头引入 → 结尾"agentic 时代，靠这套工具箱" |

## 9. 开头的 hook 密度 🟡 P1

开头 100 字内必须有 1 个**数据锚**或**反差句**。**禁止**用"今天我们来聊聊 X"开头。

| ❌ 弱开头 | ✅ 强开头 |
|--------|----------|
| "今天我们来聊聊 30 个 system prompt" | "区分'拿到泛泛 AI 输出'和'每次都能拿到专家级结果'的，只有一件事。" |
| "我最近用了 Claude，觉得很好" | "凌晨 2 点 Claude 给我写了 2000 字会议纪要——上周我花了 6 小时。" |
| "Prompt engineering 很重要" | "99% 的人用了 Claude 一年，还在用 zero-shot" |

## 10. 公众号调性检查（最终交付前必跑） 🔴 P0

每篇公众号改编的最终交付前，逐项检查：

- [ ] 开头 100 字内有 1 个数据锚或反差句
- [ ] 至少 1 个 emoji section 锚
- [ ] 至少 1 处 Bilingual prompt 名（中文 + 英文括号）
- [ ] 至少 1 处"前辈/过来人"语态（"我用了 X 之后" / "过去几个月" / "去年 X 时候"）
- [ ] 至少 1 处"先做 / 立刻 / 现在就" 行动 CTA
- [ ] 至少 1 处"❤️ / 🙏 / :)" 情感 emoji
- [ ] 全文不出现"颠覆性 / 赋能 / 抓手 / 势能"AI 公众号爆款词堆叠
- [ ] 全文不出现"自含 / 给到者 / 跑出" 直译 jargon

## 11. 节奏感 🟢 P2

每 4-6 段必有一个视觉断点（空行 / 加粗小标题 / 引用块 / 列表）。**禁止**大段连续散文超过 8 句。

| ❌ 节奏差 | ✅ 节奏好 |
|--------|----------|
| 3 段 600 字无任何断点 | 3 段每段 200 字 + 1 个加粗小标题 + 1 个列表 |

## 12. 资深编辑 vs AI LLM 的区别 🟢 P2（元信息，不作为检查项）

| 维度 | LLM 自动改 | 资深编辑 |
|------|----------|---------|
| 检查错误类型 | 硬错（grep 抓得到：翻译腔/动宾跨域/名词堆叠）| 软错（grep 抓不到：jargon 直译/营销圈习惯/微节奏）|
| 跨文化词汇 | 经常直译 | 必查表 |
| 行业子圈子 | 一刀切 | 区分 AI 圈 / VC 圈 / 创业圈 / 营销圈 |
| 营销圈术语 | 避而不译 | 主动本地化 |
| 公众号调性 | 按"记者克制"翻译 | 按"公众号爆款"改写 |
| 段首 hook | 不知道要 hook | 必查 100 字内有数据/反差 |

**核心心法**：LLM 做翻译 80 分靠 C2 grep，资深编辑做最后 20 分靠经验和行业习惯。两者互补，缺一不可。

## 历史教训

- 2026-06-09：30 prompts 翻译 C2 全过 0 触发，但资深编辑视角下发现 16 处软错
  - 5 处英文 jargon 直译（自含/反馈给到者/deck/SOC/Traction）
  - 3 处跨文化行业词汇（Pitch Deck/JD/harness）
  - 5 处营销圈通用语（反直觉断言/表达完整/无情剔除 等）
  - 3 处微节奏/微气势（搭重复/跑出/运转起）

## 何时跳过本清单

- 翻译场景是**学术论文 / 论文翻译**——保留英文术语是学术规范，跳过全清单
- 翻译场景是**纯技术内部文档**——不需要公众号调性，**仅执行 P0 三层**（§1 jargon / §6 加注 / §10 调性检查）
- 翻译场景是**内部研究简报**——不需要营销圈术语，跳过 §3/§7/§8/§10，保留其余
- **快路径（阶段 1.5 判定）**——P0 三层必做，P1 只抽 2 项，P2 全跳过
