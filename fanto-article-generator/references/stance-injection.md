# 作者立场注入（C4 立场闸门）

> 由 `SKILL.md` 阶段四步骤 7.6 按需加载。解决这套引擎的根短板：**"观点永远是原文作者的（转载感）"**——要做成个人号，需要一句**你自己**有棱角的判断，而不是复述或吹捧。

## 一、定位与触发矩阵

| 模式 | C4 强度 | 说明 |
|---|---|---|
| A 番外 | **必做** | 大白话科普最怕没立场，补"我为什么觉得这很重要" |
| C 转述 | **必做（重）** | 转述最容易变成"替原文做搬运"，立场=档位差 |
| D 认知重构 | **必做** | 已有"认知锚点前置"，顺势升级成正式闸门 |
| B 快讯 | N/A | 新闻调性，不掺个人立场，标 N/A 跳过 |
| R 微调 | 跳过 | 只改自己原稿，不动立场 |

## 二、为什么前置下种而非结尾硬堵

结尾（C3.6 之后）再注入立场 = 正文变了 → 要重跑 C2/C3/C3.5 → 多一层返工。模式 D 已有先例（默认快模式"先确认 1 句认知锚点再写"）——C4 把认知锚点前置推广到所有承担观点输出的模式，让立场参与塑形，而不是当补丁。

## 三、执行：独立 stance subagent

**不要由主 agent 顺手写立场**——主 agent 写"我的观点"会讨好安全默认值，这与 C1.5 四人格同理（让同一个模型在自己盲区里演出"审自己"）。用一个**专门 stance subagent**，被明确授权"可以不同意原文"。

**subagent 输入**：
- 源材料核心事实（C1 保真译版 / 中文源文，或该主题的真实要点）
- 已定标题（阶段三产出）
- 目标模式（A/C/D）
- 一条硬命令：**立场只能评价，禁止编造**

**subagent prompt 模板**（复制进 Agent 调用）：

```
你是本文作者。下面给的是源材料事实 + 已定标题。你要产出一条有棱角的个人立场，
不是复述原文，不是"这篇文章总结得很好"，而是你对这堆事实的【评估 / 排序 / 加权 / 联系读者】。

硬边界：
- 允许：对已有事实的评价、判断、排序、优先级；指出"我最先没想到""我有保留"；
  把事实联系到某个具体读者处境。
- 禁止：新增源材料没有的数字/事实/因果；把不确定性写成必然；把"作者以为"说成"事情就是这样"。
- 判定口诀："其实 / 实际上"两个词一出，九成在造假。立场是"我怎么看"，不是"事情其实是那样"。
- **立场句自禁模式**（越锋利越易踩去AI味，见 ai-humanize-gates H2/H4）：立场句**禁用**——`不是…而是…` 否定翻转（除非刻意对比，否则改直述）；新增破折号 `——`（计入全文 ≤2/篇预算；破折号已爆表的稿子尤其不要再加）；感叹号 `！`；`不得不说 / 值得深思` 等路标语；被动句。

围绕 4 点输出（每点 ≤2 句）：
1. 原文的结论（别人说的）：客观转述 1 句。
2. 我要补充/反对/意外的一点（我的原创判断）：1 句，必须含第一人称（我/我们/我不认同）。
3. 这跟目标读者有什么关系（so what）：1 句，具体到角色+场景（禁写"对AI感兴趣的人"）。
4. 立场落点：放在开篇钩子 / 第 X 节 / 金句之前？一句还是两句？

只输出这 4 点，不要多余客套。
```

**主 agent 动作**：用返回的第 2/3 点写入正文（开篇钩子或收束处），第 4 点定位。写完用下节边界清单复验。

## 四、强制输出（阶段四A0）

```
[强制输出—阶段四A0：作者立场预热]
1. 原文的结论（别人说的）：[…]
2. 我要补充/反对/意外的一点（我的原创判断）：[…]
3. 这跟目标读者有什么关系（so what）：[…]
4. 立场落点：[开篇钩子 / 第 X 节 / 金句之前] + 一句 or 两句
```

## 五、交付前复验（阶段四B 新增项）

- `作者立场已落进正文 ✅/❌（引用 file:line）/ N/A（B/R）`
- 未落进 = 立场只存在于预热块 → 打回注入，禁止交付。
- **受后续质控保护（R3）**：立场句在阶段四的 C1.5/C3.6 中被视作锚点——压缩（第 2 道）与"删占位符"（第 3 道）跳过，只允许不改变立场原点的动词微调与不模糊边界的分句；禁止改第一人称承诺、削限定语、焊进转述事实句、增补新事实。
