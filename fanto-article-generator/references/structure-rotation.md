# 结构池与近文轮换（structure rotation）

> 配套 `scripts/rotation_check.py`（检测近文重复）。本文件是「应然」结构骨架库：登记各模式可复用的结构 id 与结构特征，供 agent 定稿前对照「近文实况」做轮换决策。
> 本文为纯规则，不含溯源叙述。目标：把「每篇必换」的高频暴露句变成可检查、可执行。

## 一、为什么轮换（原则）

- 结构骨架可以复用（同一模式本就该用固定骨架），但**高频暴露文本必须每篇唯一**：
  开头句、结尾句、过渡句、导语收尾句。
- 读者在公众号列表划到同一句话两次 → 直接归类为「AI 水文」。这是去模板化最硬的信号。
- 轮换 = 结构可复用（骨架 id 不变），暴露句必换（开头/结尾/过渡不写重）。

## 二、结构池（骨架 id → 结构特征）

agent 写正文前先在本表登记「本文用哪个骨架 id」，再跑 `rotation_check.py` 比对近文。

| 骨架 id | 模式 | 结构特征（H2 形态 / 章节形态） | H2 章节数 |
|---|---|---|---|
| A1 | A 番外·应用/方法类 | 标题 `# 番外篇 X｜…？谈谈专业概念：术语`；H2 一~六；Mermaid（含机制）；末尾「用一句话总结」 | ~6 |
| A2 | A 番外·职业/角色类 | 同 A1 标题；H2 一~八；含「岗位画像/制度机制/团队角色/门槛/适用边界」 | ~8 |
| A3 | A 番外·方法论/工作流类 | 同 A1 标题；锚点+弹性环节，可增减调序；含「病象解剖/核心方法全貌(Mermaid)/落地验证/注意事项」 | 弹性 ~5 |
| B | B 快讯 | 标题无 `番外篇` 前缀，主体+事件+关键信息；H2 四节 | 4 |
| C-di | C 对话转述 | 导语三段式；8-10 章，章节独立可跳读；含大量引语；结尾两段式 | 8-10 |
| C-tut | C 教程转述 | 场景+痛点开篇；步骤式正文 `## N. 步骤标题`；结尾效果对比+来源标注 | 步骤式 |
| C-essay | C 观点转述 | 对话骨架简化版；观点推进为主，引语为辅 | ~6 |
| D | D 认知重构 | 开头认知反差「我以为 X 是 Y，直到…」；H2 一~五；结尾一句话「带走的认知」 | ~5 |

### 骨架 id 判定（写前必填）

- 按 mode 文件的概念类型判定（mode-a.md 1.5 步）选 A1/A2/A3；B 固定 B；C 按源材料形态选 C-di/C-tut/C-essay；D 固定 D。
- 判定后，在阶段四A 输出的「章节结构方案」里**必填骨架 id**（如 `结构轮换：骨架 A2`），供 rotation_check 对照。

## 三、高频暴露句纪律（每篇唯一）

| 类别 | 约束 | 违纪信号 |
|---|---|---|
| 开头句 | 第 1 段首句不得与近文任一开头句重复 | 与近文开头句 >80% 相似 |
| 结尾句 | 末段「带走的」结论/判断句不得与近文结尾句重复 | 与近文结尾句 >80% 相似 |
| 过渡句 | 章节间衔接句、导语收尾句不写同一个套话 | 出现同一理由标记词（如下） |
| 标题结构 | 同骨架 id 允许，但标题句不得与近文标题同型同义 | 标题>5 字连续重叠 |

### 高频暴露句禁用「套话模板」（出现即改，让位给具体事实/数字/判断）

- 开头：`你可能见过这个场景：`、`先看一个问题：`、`你有没有想过`、`当下 AI 圈最热的是`。
- 结尾：`一句话总结`、`总的来说`、`这就是 X 的意义`、`未来已来`。
- 过渡：`值得注意的是`、`尴尬的是`、`更有意思的是`、`其实`、`说到底`。

> 这些套话不是绝对禁用——当它承载具体事实时保留；单独站队当口头禅时删。用具体事实/数字/差异句替代。

## 四、轮换决策（定稿前执行）

写正文前（阶段四A 构思末）跑 `rotation_check.py`，读它输出的冲突清单：

1. 重复开头句 / 结尾句 / 过渡句 → **必须换**（换表达开头的具体场景，或提前结尾判断句）。
2. 连续 2-3 篇同骨架 id（如 A2 连着 3 篇）→ **提示换结构**（改用 A1/A3 或调整章节顺序）。
3. 跳过检查 = 视同自检不合格。重复未修不得进入交付。

## 五、近文实况对照

- 检测对象：`output/*/index.md` 正文（frontmatter 仅有 title/cover，无 mode/structure 字段，故签名从正文提取）。
- 比对范围：最近 N 篇（默认 6）。同一篇只要开篇/收尾/骨架特征相同即报冲突。
- 签名提取（启发式，允许误判）：
  - **结构签名**：全部 H2 标题形态 → 映射骨架 id（见第二节表）。
  - **开头句**：首个非标题非 blockquote 的正文段落首句。
  - **结尾句**：末段去掉 `*本文…*`/`*来源：*` 来源标注后的实义句。
- 撞上误判时，以「人类判断为准」：签名相近但表达确实不同 → 放行；判定阈值见 `rotation_check.py --help`。
