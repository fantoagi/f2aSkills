# v2 R 修订闸门（Revision Gate）

R 保留原稿并按影响范围分流，不把每一次改字都误判为整篇重写，也不让结构或事实修改逃过回归检查。

## 路由

- **R1**：句子和段落级修改；核心命题、事实方向和结构不变。
- **R2**：章节顺序、衔接和信息层级调整；必须重查标题承诺、开头、结尾和跨章节指代。
- **R3**：观点、证据和立场修订；必须重新确认 C4、反方观点和主张账本。
- **R4**：事实、引用、数字和日期纠错；必须重新核验受影响主张、引用和上下文。

## 必填修订记录

每次 R 任务在 `runlog/<topic>/stage-06-audit.md` 或独立修订记录中写明：

```markdown
## Revision Audit

- 用户要求：
- 修订模式：R1 / R2 / R3 / R4
- 受影响位置：文件、章节、段落或行号
- 是否影响核心命题：是 / 否
- 是否需要重新检查前后文：是 / 否；原因：
- 是否升级 Standard：是 / 否；原因：
- 修改后的验证结果：C2、claims、technical gate、reader value 或人工复核结果
- 仍待确认：
```

## 升级规则

- 触及核心命题、事实方向、引语含义或整体结构：升级 Standard。
- 只改语气、错别字或局部衔接：可留在 Lite/R1，但仍需确认未改变原意。
- 修改数字、日期、专名或引用：至少执行 R4 记录和 claims 回查。
